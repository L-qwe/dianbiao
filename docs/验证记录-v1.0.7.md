# v1.0.7：总电量表格与精简遥测

## 行为

- 删除当前功率显示和 `/api/status` 的 `power_kw`，同时删除 15 秒脉冲频率/功率估算；GPIO 中断、脉冲校验、累计值及 NVS 格式保持兼容。
- 总览表格固定 3 行 4 列，依次显示 CH1～CH12；上方为配置中的通道名称，下方为总用电量，单位 kWh，保留 3 位小数。停用通道仍显示已有总电量。
- 总电量继续使用 `初始电量 + 累计脉冲 / 脉冲常数`；12 路默认常数仍为 1600 imp/kWh。表格随状态轮询更新，数据不变时不重建内容。
- 原来的累计脉冲、GPIO、脉冲常数及使能状态放入“通道采集详情”，默认收起。
- 心跳包含设备信息及全部 12 路总电量；周期电量报文同样精简。每个通道只发布 `ch`、`name`、`energy_kwh`，不再附带 GPIO、累计脉冲、脉冲常数、初始电量或使能状态。
- 心跳间隔和电量上报间隔继续独立配置。关闭周期电量上报时，心跳仍包含总电量。主动查询配置和保存配置后的配置回执保留，类型为 `meter_config`。

## MQTT 字段

心跳顶层：`<MAC>_online`、`msg_type=heartbeat`、`dev_mac`、`device_name`、`version`、`ip`、`rssi`、`time`、`ntp_ok`、`uptime_s`、`free_heap`、`report_interval_s`、`meters`。

周期电量顶层：`msg_type=meter_energy`、`dev_mac`、`time`、`report_index`、`meters`。

二者的 `meters` 都包含 12 个以下结构的对象（示例为一个通道）：

```json
{"ch":1,"name":"电表01","energy_kwh":177.160}
```

消费端如需读取原来的配置字段，应使用 `meter_config` 配置回执。原有 `<MAC>_online` 在线字段和发布/订阅 Topic 展开规则保留。
