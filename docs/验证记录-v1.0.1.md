# v1.0.1 · QC 风格 Web 门户

采用 QC_ESP32 的背景色 `#0d141b`、面板色 `#151f29`、强调色 `#51e0b7`、边框色 `#2b3b49`，统一字体、间距、圆角、按钮、顶部导航、状态徽标和表单。

实时总览使用 12 路卡片显示电量、脉冲、常数和功率；配置页改为独立通道卡片，手机无需横向滚动表格即可填写。MQTT/系统保留单个完整表单，避免分区保存时遗漏其他配置；密码增加显示开关。OTA 示例使用代码框，Wi-Fi 扫描、密码、连接状态和保存提示页采用同一主题。

本次保留 `status_json` 及其后全部后端代码，已与改动前源文件逐字比较。计量、NVS 存取、GPIO、MQTT、Wi-Fi 应用、OTA 与配置保存处理逻辑未修改。

## 浏览器验证

从实际 C++ 页面生成函数提取并在主机编译，使用模拟设备配置生成 HTML，再通过本地 HTTP 服务和 Edge 浏览器验证；不是手写的独立页面样稿。浏览器请求均由模拟端点处理，没有实际清零、配网、升级或重启硬件。

- 总览、采集配置、MQTT/系统、Wi-Fi、OTA、密码、连接状态七个页面，在 320、360、390、620、1000、1440 像素宽度下无页面横向溢出，导航高亮与当前页面一致，顶部刷新按钮保持一行。
- 总览完整呈现 12 路数据和使能状态；读取失败显示数据过期提示，恢复后清除提示；特殊字符名称按文本显示。
- 12 路配置字段完整，核对名称、初始电量、脉冲常数、复选框及 POST 参数；清零仅携带被点击通道的清零按钮参数，同时提交完整配置。
- MQTT/系统的 19 个原有字段全部保留并随一个 POST 提交；热点密码与 MQTT 密码默认隐藏、显示开关正常。
- 网络扫描轮询、同名网络去重、开放/加密网络入口、特殊字符转义、手动连接及密码页提交参数通过验证。
- OTA 的 URL、MD5、文件大小按原接口参数提交，包括 URL 中的 `&` 等字符。
- 页面执行无 JavaScript 异常。
- 在 320 像素宽度下补查较长设备名和通道名，内容在区域内换行，启用/停用徽标保持一行。

## 固件构建

`platformio run -e esp32-s3-devkitc-1` 构建通过，环境配置为 16 MB Flash、8 MB OPI PSRAM。静态 RAM 占用 54,764 字节（16.7%），应用约 1.08 MB，低于 2.5 MB OTA 槽容量。

使用 `scripts/package_firmware.ps1` 交付 v1.0.1 的 16 MB OTA 应用及首次串口烧录合并镜像，并记录大小、MD5、SHA256。打包前检查源文件更新时间，防止交付过期构建。
