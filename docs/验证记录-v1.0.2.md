# v1.0.2 · 热点 Web 架构重构

本版将 v1.0.1 的动态多页面改为 QC_ESP32 式静态单页与 JSON API，并优化配网、MQTT 重连、BLE 状态通知和计数保存中的等待/重复工作。实现与接口见 [Web 架构](Web架构.md)。

## 验证范围

测试直接编译实际生产代码的校验、MQTT、BLE、HTTP 预解析与计数持久化逻辑；外围 Wi-Fi、任务通知、串口和 NVS 使用可记录/可失败的替身。浏览器从实际 `web/index.html` 加载，所有请求由本机模拟设备处理，没有操作实板。

| 命令 | 结果 |
|---|---|
| `node scripts/test_web.cjs` | 单次 HTML 加载覆盖全部标签和操作；接口延迟 900 ms 时本地标签可切换；卡片/输入节点、焦点、选择区和草稿保持；相同数据连续渲染 30 次没有卡片内容节点修改；状态轮询至多一个在途请求；后台暂停、掉线/配置读取恢复通过 |
| 同上 | 12 路配置保存/清零、系统差量提交、密码显示、网络扫描去重/转义、开放网络、中文及特殊字符凭据、连接失败重试、旧关联不误报成功、OTA JSON 参数通过；五个标签在 320、360、390、620、1000、1440 px 无页面横向溢出；无 JS 异常 |
| `python scripts/test_portal.py` | 配置类型/范围、部分字段更新、12 路完整性与通道去重、UTF-8 名称长度、无效末尾字段不修改运行配置、清零范围、10 秒重试及 millis 回绕通过 |
| `python scripts/test_mqtt_worker.py` | 故意挂起真实 MQTT 实现的握手调用，主循环维护/状态/发布入口仍返回；没有并发访问同一客户端；任务分配失败不退回同步连接；10 秒冷却、冻结凭据、成功交接、Wi-Fi 断开通过 |
| `python scripts/test_ble_job.py` | 实际 BLE 循环重发通知不推进模拟时间；排队/断开旧关联期间不报告旧网络成功；新作业完成、失败、超时状态通过 |
| `python scripts/test_meter_persistence.py` | 实际计量代码每次保存只打开一次 NVS；仅写变化通道；首次初始化覆盖未标记的旧键；重启恢复、单路清零隔离、写入/打开失败重试、保存期间新增脉冲不丢失通过 |
| `python scripts/test_http_transport.py` | 实际 HTTP 预解析器提前拒绝 TLS/二进制、限制日志频率；正常/分段请求与拒绝后的恢复通过 |

主机 C++ 测试使用 `python -m ziglang c++`。浏览器测试使用 Playwright 与本机 Edge；可通过 `npm install --prefix .pio/web-test --no-save playwright` 安装依赖。

## 固件交付

PlatformIO 环境 `esp32-s3-devkitc-1` 配置为 ESP32-S3 N16R8（16 MB Flash、8 MB OPI PSRAM）。使用 `scripts/package_firmware.ps1` 生成 v1.0.2 的 16 MB OTA 与首次串口烧录镜像，大小与哈希记录在 `dist/manifest.json`。

最终构建通过：静态 RAM 55,188 字节（16.8%），Flash 应用代码/数据 1,081,105 字节（41.2% 的 OTA 槽）。构建生成的页面与 `web/index.html` 一致；配置持久化实现与 v1.0.1 除版本号/文件末尾换行外一致，MQTT 报文构造除客户端所有权检查外一致；分区表二进制与 v1.0.1 首次烧录镜像对应区域完全相同。

原分区表、GPIO 映射、计量公式、脉冲最小间隔、NVS 命名空间/键名、MQTT 报文和 BLE UUID 保留；计数持久化实现调整为批量/变化保存，不迁移格式。应用升级使用 OTA 文件，无需上传文件系统。
