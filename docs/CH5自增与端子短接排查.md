# CH5 空载自增、各端子短接不计数

后续结论：用户已确认供电存在问题，修正供电后问题解决。以下保留为当时的排查记录，不代表已确认 U6 或 U14 损坏。

## 本次证据和边界

用户提供的日志仅显示 CH5/GPIO8 自增，约 115～280 秒从 0 增至 562。通过校验的高电平包括 1～数毫秒，也包括 `high_us=1960703`、`3629756` 等秒级跨度。因此不能将本次异常全部解释为小于 1ms 的毛刺。

日志是固件在中断内读取 GPIO 的结果，不是示波器测量；尚未取得实际供电、电平、器件装配及开发板排针信息，不能确定是某个焊点或芯片损坏。历史文档中的 GPIO10/GPIO11 互补关系属于之前的日志，本次不据此推定 U15 焊桥。

已重新运行 `python scripts/check_meter_netlist.py`：12 路网表映射通过。已运行 `python scripts/test_meter_persistence.py`：生产计数代码的完整脉冲、毛刺过滤、启动状态、持久化及日志测试通过。这些检查不能代替实板测量。

CH5 对应：

`CN5 → U6/H11L1M → R15/RC06 → U14.13 → U14.12 → H1.12/GPIO8`

注意 RC 网络编号与 CN 编号并不相同。CH5 的上拉是 R14（4.7kΩ），串联电阻是 R15（1kΩ），电容是 C10（10nF）；光耦 LED 限流电阻是 R13（1kΩ）。

## 先确认操作与供电

1. 不接电表，短接**同一个 CN 的 1、2 脚**约 0.5 秒，再断开约 0.5 秒，重复数次。当前代码在高电平结束的下降沿计数，持续短接不会连续加数；日志每路最多每秒输出一次。
2. 测量以下电源，所有电压以底板 GND 为参考：H1.21/5V_MAIN 约 5V；H1.1/VCC 约 3.3V；U6.6 约 5V、U6.5 为 GND；U14.14 约 3.3V、U14.7 为 GND。
3. 只接开发板 USB 时，不能仅凭 ESP32 已启动就认定底板得到 5V；实测 H1.21 与 U6.6。若所有通道都不响应，公共电源、地、排针兼容和插接方向优先检查。

U14/U15 的设计型号为 SN74LVC14APWR，供电接 3.3V。不要将其 VCC 改接 5V。N16R8 描述模块存储配置，不能保证第三方开发板与标准 DevKitC-1 排针一致。

## 沿 CH5 测量

保持正常低压供电，万用表黑表笔接底板 GND。先测 CN5 空接，再保持 CN5 两脚短接，便于读稳定电压。芯片脚号以实物圆点/缺口及数据手册为准，避免表笔跨接相邻脚。

| 测量位置 | CN5 空接时预期 | CN5 短接时预期 |
|---|---:|---:|
| U6.6（检测侧电源） | 约 5V | 约 5V |
| U6.4（光耦输出） | 约 3.3V | 低电平，通常低于 0.4V |
| U14.13（RC06 输入） | 约 3.3V | 接近 0V |
| U14.12（反相器输出） | 接近 0V | 约 3.3V |
| 开发板 GPIO8（H1.12） | 接近 0V | 约 3.3V |

以上是正常电路的预期值；万用表平均值无法排除动态干扰，必要时用示波器同时观察输入和输出。

按第一个偏离预期的位置定位：

- 电源不对：先查供电与地、H1 接触和实物开发板排针，不继续以计数现象判断光耦好坏。
- U6.4 空接时不为高：查 R14 上拉、U6 供电/方向、连锡和异常漏电。
- U6.4 短接后不拉低：测 R13 两端压降。1kΩ 上每 1V 压降对应约 1mA。正常 5V 回路估算为数 mA；若几乎没有压降，查 DB5、R13、U6 LED 极性和 CN5 通路。电流充足但输出不翻转，再查 U6 型号、方向、供电或损坏。
- U6.4 正常、U14.13 不正常：查 R15、C10 与相连焊点/走线。
- U14.13 稳定、U14.12 异常：查 U14 实物型号、方向、供电、相邻脚焊接和输出负载；用示波器排除输入动态波动。
- U14.12 正常、开发板 GPIO8 不正常：查 H1.12 接触、走线和开发板实际引脚对应。
- GPIO8 能稳定随短接/断开翻转而不计数：再核对实机固件版本、启动日志和已烧录镜像，软件排查才有明确依据。

正常电路中，端子空接时 GPIO8 由反相器主动驱动为低，不应悬空。内部弱下拉不能消除外部器件主动输出的异常翻转；继续加大软件门限可能掩盖故障并漏掉有效电表脉冲。

## 器件依据

- [TI SN74LVC14A 数据手册](https://www.ti.com/lit/ds/symlink/sn74lvc14a.pdf)：TSSOP 的 13 脚为输入、12 脚为对应输出，14 脚为 VCC、7 脚为 GND，器件供电范围 1.65～3.6V。
- [onsemi H11L1M/H11L2M/H11L3M 数据手册](https://www.onsemi.com/pdf/datasheet/h11l3m-d.pdf)：H11L1M 的指定条件最大开启阈值 1.6mA，低电平输出上限 0.4V；实测和设计裕量应结合手册条件判断。
- [Espressif DevKitC-1 排针表](https://docs.espressif.com/projects/esp-idf/en/v5.2/esp32s3/hw-reference/esp32s3/user-guide-devkitc-1-v1.0.html)：标准 J1.12 为 GPIO8，J1.21 为 5V，J1.22 为 GND。
