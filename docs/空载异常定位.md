# 空载异常定位：GPIO10/GPIO11 互补边沿

依据用户新提供的 v1.0.5 诊断日志分析，当前异常涉及 CH5/GPIO8、CH8/GPIO10、CH9/GPIO11。没有实板测量，因此下述是待验证的定位假设，不是已确认的焊接故障。

## 时序证据

多组 CH8、CH9 的高低时长互相对应：

| 一路高电平时长 | 另一路低电平时长 | 差值 |
|---|---|---:|
| CH9：661565µs | CH8：661566µs | 1µs |
| CH8：278439µs | CH9：278440µs | 1µs |
| CH9：473433µs | CH8：473433µs | 0µs |
| CH9：775626µs | CH8：775626µs | 0µs |
| CH9：132769µs | CH8：132769µs | 0µs |

用 `at_us + high_us` 求出观测下降沿，再和另一路上升沿比较：

| 下降沿来源 | 下降沿时间戳 | 另一路上升沿 | 差值 |
|---|---:|---:|---:|
| CH9：137516896 + 661565 | 138178461 | CH8：138178460 | −1µs |
| CH8：205949185 + 278439 | 206227624 | CH9：206227626 | +2µs |
| CH9：206227626 + 473433 | 206701059 | CH8：206701057 | −2µs |
| CH9：232018646 + 775626 | 232794272 | CH8：232794271 | −1µs |

这强烈提示 GPIO10/GPIO11 在近乎同一时刻反向变化。时长来自 ISR 采样，不替代示波器，但重复出现的互补关系足以把两路耦合列为优先检查项。GPIO10 还记录到约9.87秒、21.30秒的高电平跨度，不能靠单纯加大1ms过滤门限解决。

## 对应电路与首要假设

依据 TEL 网表及 SN74LVC14A 的 TSSOP 引脚定义：

- CN8 → U9 → R26/RC08 → U15.3（2A）→ U15.4（2Y）→ GPIO10/H1.16。
- CN9 → U10 → R29/RC09 → U15.5（3A）→ U15.6（3Y）→ GPIO11/H1.17。

**U15.4 是 GPIO10 的输出，紧邻的 U15.5 是 GPIO11 对应反相器的输入。** 如果这两个焊盘发生连锡或走线误连，GPIO10 就会被送入下一组反相器，GPIO11 随之呈反相。这与日志特征相符，应优先验证。其他误连、芯片损坏、实际封装脚号/器件与设计不一致或动态耦合，也需要实测排除；不能仅凭日志判定一定是4/5脚焊桥。

依据：[TI SN74LVC14A 引脚定义与反相逻辑](https://www.ti.com/lit/ds/symlink/sn74lvc14a.pdf)。

## 检查顺序

1. 断开底板12V和所有USB，拔下开发板后，再用万用表电阻档测 U15.4 与 U15.5。依据芯片缺口/圆点确认脚号，不凭截图方向猜。关注是否持续接近0Ω；电容充电引起的短暂蜂鸣不能单独认定短路。
2. 放大观察 U15 的3～6脚与相连走线，重点检查4/5脚、3/4脚、5/6脚之间是否有连锡或导电杂物。若确认焊桥，清理后重新测量。
3. 恢复正常低压供电，所有 CN 空接，测量下表各点，并核对 U15.14 约3.3V、U15.7 为GND。静态电压只用于初查。

| 通道 | 反相器输入，预期约3.3V | 输出，预期稳定约0V |
|---|---|---|
| CH8/GPIO10 | U15.3（RC08） | U15.4 |
| CH9/GPIO11 | U15.5（RC09） | U15.6 |
| CH5/GPIO8 | U14.13（RC06） | U14.12 |

4. 若未发现直流低阻误连，使用示波器同时看 U15.4、U15.5、U15.6，确认 GPIO10 是否串入下一组输入；再检查 U15.3、U9/U10、R25/R28 上拉与串联支路。若底板输出稳定而开发板端不稳定，则核对 H1 接触和实物开发板排针。
5. GPIO8 的支路独立检查 U14.12/13、R14/R15、U6，不能仅因另外两路相关就认定三路具有相同根因。

此轮未改固件阈值或原始网表。Web 非 HTTP 拒绝日志没有直接增加脉冲数的代码路径；网络活动是否有间接电源/电磁影响，仍需对照波形，不从日志时间直接推断。
