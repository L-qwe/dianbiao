# 电表采集底板与 ESP32-S3 引脚核对

依据用户提供的 `image.png` 和 `电表采集PCB.tel` 核对。TEL 是连通网表，不包含实际 PCB 走线、间距、安装方向或已焊器件信息，不能据此认定 PCB DRC 或实板电气测试通过。

## 通道与接口

## 电平、极性与输入类型

图中 U14/U15 是 **SN74LVC14APWR**，v1.0.4 已修正源码中的器件名称注释。其 14 脚由 VCC/3.3V 供电，7 脚接地。各 H11L1M 的检测侧使用 5V_MAIN，开集电极输出通过 4.7kΩ 上拉到 VCC/3.3V，再经过 1kΩ、10nF 和 LVC14 送到 GPIO。因此，按此供电与正确器件装配，不是把 5V 推挽信号直接送到 ESP32。

对于隔离的无源开集电极脉冲口，预期脉冲正端接 CNx.1，负端接 CNx.2。回路为 `5V_MAIN → BAT54H → 1kΩ → 光耦 LED → CNx.1 → 电表输出开关 → CNx.2/GND`。按 LED 约 1.2V、二极管及开关压降合计约 0.5V 估算，导通电流约 3.3mA；实际最小电流取决于电表输出残压、供电、器件温度及线缆压降，不能用此估算替代实测。H11L1M 手册在指定测试条件下给出的最大开启阈值为 1.6mA。

输出开关断开时，光耦 LED 熄灭，光耦输出为高，LVC14 输出/GPIO 为低；输出开关导通时，光耦输出拉低，LVC14 输出/GPIO 为高。GPIO 为高有效。v1.0.3 使用上升沿计数，v1.0.4 改为 `INPUT_PULLDOWN + CHANGE` 并校验完整脉冲：低电平至少 1ms 后开始，高电平至少 1ms 后回低才计数。串联 RC 的放电/充电时间常数约为 10μs/57μs，不会成为 50Hz、毫秒级脉冲的主要限制；极短脉冲的通过能力仍需根据实际波形核实。

依据：[TI SN74LVC14A](https://www.ti.com/lit/ds/symlink/sn74lvc14a.pdf)、[onsemi H11L1M](https://www.onsemi.com/download/data-sheet/pdf/h11l3m-d.pdf)。

## 共地与尚待确认项

**全部 CNx.2 与 ESP32、光耦检测侧、12V/5V 供电使用同一 GND，输入侧也使用同一 5V_MAIN。底板未实现输入侧与逻辑侧的电气隔离。** 光耦器件的隔离额定值不能当作这张底板的隔离能力。

若电表输出本身是与市电可靠隔离的低压无源脉冲口，这种共地低压采集方案可继续联调。不得将 CN 端子接到电表的市电端子或未经确认的非隔离输出。若底板必须提供独立隔离，需要把现场侧供电/地与逻辑侧供电/地分开，并重新检查 PCB 隔离间距；无法靠固件实现。

DDS606 的厂家、完整子型号、脉冲口隔离性质、输出类型、允许回路电压/电流和极性尚待用户确认，不能仅凭 DDS606 名称推定。另需确认开发板 USB 与底板外部 5V 同时连接时的电源路径；官方开发板将 USB、5V 排针和 3.3V 排针供电列为互斥方式，第三方板以实物电路为准。
